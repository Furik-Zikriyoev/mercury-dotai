# Mercury DotAi

Аналитика игрока Dota 2: профиль, герои, матчи, сравнение с другим игроком, разбор статистики и чат с ИИ-коучем.
Данные матчей берутся из открытого API OpenDota прямо в браузере, ИИ — через OpenAI на сервере.

Два способа войти:

- **Регистрация** со своим Steam ID — для тех, кто играет. Лимит запросов к ИИ — 40 в сутки.
- **Демо без регистрации** — открывает профиль тестового игрока. Лимит — 8 запросов к ИИ в сутки на IP. Ссылка сразу в демо: `/?demo=1`.

## Устройство

```
public/        страницы (HTML + CSS + JS без сборки)
  js/app.js    общее: адрес API, сессия, экранирование, плашка демо-режима
server/        API на Express
  app.js       сборка приложения
  auth.js      регистрация, вход, демо, сброс пароля
  ai.js        разбор статистики и чат, лимиты
  limits.js    лимиты частоты и суточные квоты (счётчики в БД)
  prompts.js   промпты
api/index.js   точка входа для Vercel
dev.js         локальный сервер: API + статика
```

База — SQLite через libsql: локально файл `data/local.db`, в продакшене Turso.

## Безопасность

- Секреты только в переменных окружения, сервер не стартует без `JWT_SECRET`.
- Все запросы к ИИ — только после входа, с суточным лимитом на пользователя (для демо — на IP) и общим потолком на сервис. Неудачный запрос не списывается.
- Лимиты частоты на вход, регистрацию и сброс пароля.
- Токен сброса пароля одноразовый, живёт час, в БД хранится только его хеш.
- Промпт собирается на сервере из проверенных значений. Клиент не может подменить системную инструкцию.
- Ответы ИИ и ники игроков экранируются перед вставкой в страницу.
- Фронт и API на одном домене, CORS не открыт.

## Запуск локально

```bash
npm install
cp .env.example .env   # вписать JWT_SECRET и OPENAI_API_KEY
npm run dev            # http://localhost:3000
```

## Деплой на Vercel

1. Создать базу в [Turso](https://turso.tech): `turso db create dotai`, затем
   `turso db show dotai --url` и `turso db tokens create dotai`.
2. Импортировать репозиторий в Vercel (Framework Preset: Other, настройки сборки не нужны).
3. Вписать переменные из `.env.example` в Settings → Environment Variables:
   `JWT_SECRET`, `DATABASE_URL`, `DATABASE_AUTH_TOKEN`, `OPENAI_API_KEY`, `DEMO_STEAM_ID`, `APP_URL`, при желании почту.
4. Задеплоить. Таблицы создаются сами при первом запросе.

Перенести пользователей из старого файла базы: `turso db shell dotai < dump.sql`, где `dump.sql` — результат `sqlite3 старая.db .dump`.
